# Gabriel Machine
abriel's Machine - Conversor de Bases Numéricas
Este projeto é uma ferramenta web simples desenvolvida para converter números decimais em outras bases numéricas comuns: Octal, Hexadecimal e Binário.

Sobre o projeto
A aplicação utiliza JavaScript puro para realizar os cálculos de conversão de forma instantânea. O objetivo foi criar uma interface funcional e direta, com uma estética personalizada voltada para o tema de computação.

Funcionalidades
Conversão de Decimal para Octal (Base 8).

Conversão de Decimal para Hexadecimal (Base 16).

Conversão de Decimal para Binário (Base 2).

Interface centralizada com suporte a imagem de fundo em tela cheia.

Tecnologias Utilizadas
HTML5: Estruturação dos elementos e campos de entrada.

CSS3: Estilização visual, fontes Segoe UI e manipulação de background.

JavaScript (ES6): Lógica de conversão utilizando o método toString() com diferentes parâmetros de base.

Como utilizar
Faça o download ou clone este repositório.

Certifique-se de que a imagem de fundo está no caminho correto: img/binario.png.

Abra o arquivo index.html em seu navegador.

Digite um número decimal no campo de entrada e clique no botão "Converter".
